# 🐱 ねこの相棒とふしぎの島

8才の女の子といっしょに作る、ブラウザで遊べる探索アドベンチャーゲームです。

- 主人公…女の子（リイコ）
- 相棒…ねこ（ミィ）… 敵をタップすると、この子が戦います
- 敵…ねこっぽい敵

## あそびかた

- **さわったところへ歩く**（スマホ・タブレット）／パソコンは矢印キー・WASD
- **敵をタップ** すると、相棒ねこがダッシュして戦います
- **たからばこ🎁 をタップ** で宝を手に入れる
- **人物をタップ** で会話
- 奥の「ボスネコ」を倒すと島に平和がもどります

## あそびかた（かんたんに動かす）

`index.html` をブラウザで開くだけ。
最初に「あいことば」を聞かれます。初期設定は **`neko`** です。

## ファイルのやくわり

| ファイル | なかみ |
|---|---|
| `index.html` | 画面のわく |
| `css/style.css` | 見た目 |
| `js/scenario.js` | **おはなしのデータ（ここを書きかえて新しいお話を作る）** |
| `js/engine.js` | ゲームのしくみ（ふつうは さわらない） |
| `js/main.js` | スタート・あいことば |

## 新しいお話を作るには

`js/scenario.js` の中を書きかえます。マップ・敵・宝箱・登場人物・セリフはすべてここにあります。
プログラム（`engine.js`）はさわらなくて大丈夫。

## あいことばを変える

`js/scenario.js` の一番上、`GAME_CONFIG.password` を好きな言葉に変えます。

> ※ これは「知らない人がうっかり遊べない」ていどの目隠しです。本かくてきな鍵ではありません。
