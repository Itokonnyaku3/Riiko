# 🐱 ねこの相棒とふしぎの島

8才の女の子といっしょに作る、ブラウザで遊べる探索アドベンチャーゲームです。

- 主人公…女の子（リイコ）
- 相棒…ねこ（ミィ）… 敵をタップすると、この子が戦います
- 敵…ねこっぽい敵

## あそびかた

- **リイコを うごかす**：画面の ほうこうボタン／パソコンは 矢印キー・WASD
- **敵をタップ** すると、相棒ねこ（ミィ）が ダッシュして 戦います
- **じめんをタップ** すると、ミィが そこへ 行きます
- **たからばこ🎁 や 人物に ぶつかる** と、あいたり 話したり します
- 森を 通り抜けて、いちばん 北の 高台を めざします

## あそびかた（かんたんに動かす）

`index.html` をブラウザで開くだけ。
最初に「あいことば」を聞かれます。初期設定は **`neko`** です。

## いまのステージ

**1面「はじまりの森」**
村（ハナが さらわれる）→ 森の入口（きこりの タロが 目げき じょうほうを くれる）→ 森の広場 →
三叉路（足あとの ある まん中が 正かい）→ **ふたつの 大きな いわ の あいだ＝見た目は 森だけど 通り抜けられる** →
森の おく → 見晴らしの 高台（遠くに「やみの しろ」が 見える）

全体図 → [docs/stage1-map.svg](docs/stage1-map.svg)

## キャラの 絵を さしかえるには

`assets/` に 画像を おいて、`js/scenario.js` の 上のほうの `PLAYER_WALK` / `ENEMY_WALK` の
ような かたまりを 1つ ふやし、キャラに `walk:` と `size:` を わたすだけです。

- 128×128 の 正方形・背景とうめい（PNG）
- キャラは **下ぞろえ**（足のうらが 下から 4%の ところ）
- 4方向×2コマ：`down1 down2 up1 up2 left1 left2 right1 right2`
- みぎ向きは ひだり向きの 左右はんてん で よい
- **絵が よみこめない ときは 絵文字で 動く**ので、1つずつ 順に 置きかえられます

やることリスト → [docs/TASKS.md](docs/TASKS.md) の「PhA キャラ・画像の さしかえ」

## マップを 作りかえるには

1. `tools/map-editor.html` を ブラウザで ひらく
2. 「📚 よむ」で `stage1` を えらぶ（今の 1面が 出てくる）
3. じめんを ぬったり、いわや 木を おいたりする
4. 「💾 ファイルに だす」→ できた ファイルを `js/maps/stage1.js` に 上書き

> かざり（🌸のところ）は **ぶつからない**。だから 抜け道の 上に 木を おくと
> 「見た目は 森だけど 通れる」ばしょが 作れます（1面の なぞの しかけ）。

## 新しいお話を作るには

`js/scenario.js` の中を書きかえます。マップ・敵・宝箱・登場人物・セリフはすべてここにあります。
プログラム（`engine.js`）はさわらなくて大丈夫。

## あいことばを変える

`js/scenario.js` の一番上、`GAME_CONFIG.password` を好きな言葉に変えます。

> ※ これは「知らない人がうっかり遊べない」ていどの目隠しです。本かくてきな鍵ではありません。
