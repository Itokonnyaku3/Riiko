# 全体計画 ― 「ねこの相棒とふしぎの島」を “面白いゲーム” にする

対象プレイヤー：8才（難易度は小6相当でOK。最初は難しめ → 詰まったら自動でやさしくなる）
判断基準：**ゲームとして面白いか**。この文書は「面白さの条件 → 要件 → 検証方法」を一本の線でつなぐためのもの。

### 決定ずみ（2026-08-01）
- **主人公リイコは剣を持って自分で戦う。猫のタップ戦闘も残す**（戦い方が2つ併存）。
- **仲間は途中加入。1面はリイコひとり → 2面で仲間1＝妖精ピカ → 3面で仲間2＝猫ミィ**。
- **魔法は入れる**（3面で習得）。**最終面は魔王城**。
- **まず作るのは1面と2面**。3面以降は骨組みだけ用意して、娘の反応を見てから作り込む。
- **3面と4面は 1つにまとめる → 全4面**。
- **1面に村のプロローグを入れる**（2〜3分。会話とさらわれる場面だけ、探索はさせない）。
- **現行 stage2 マップは 1面「はじまりの森」として作り直した**（済・下記）。

## 1. 面白さの条件（設計原則 10）

要件の“親”になる考え方。すべての要件はどれかに紐づく。

| # | 原則 | 8才向けの意味 | 破ったときに起きること |
|---|---|---|---|
| A | **目標がいつも見えている** | 「お城に行く」がいつでも思い出せる | どこへ行けばいいか分からず放置される |
| B | **自分で気づいた感** | ヒントは“答え”でなく“見る場所”を教える | 言われた通りに動くだけ＝作業になる |
| C | **段階的な手応え** | 練習 → 応用 → 本番、の順で出す | 急に難しくて泣く／簡単すぎて飽きる |
| D | **さわった時の気持ちよさ** | 当たると止まる・光る・音が鳴る | 同じ内容でも「地味」と言われる |
| E | **失敗が安い** | やられてもすぐ再開、進んだ分は消えない | 1回の失敗でゲームを閉じる |
| F | **キャラが好き** | 妖精と猫が勝手にしゃべる・ふざける | 世界に居たいと思わない |
| G | **リズム（緩急）** | 謎 → 戦い → 物語 → 静けさ を繰り返す | ずっと同じで飽きる |
| H | **驚き（見せ場）** | 遠くに城が見える／友達の声が聞こえる | 印象に残る場面がゼロになる |
| I | **報酬** | 宝・新しい技・お話が進む | 探索する理由がない |
| J | **終わりが明快** | 面の終わりに達成感、次への引き | 「いつ終わったのか分からない」 |

**この10個をぜんぶ満たしていれば面白い**、という仮説で進める。検証は §9。

## 3. 物語の全体像（全5面）

**全体の筋**：ハナが魔王の手下「かげマント」にさらわれる → リイコが追う → 森・谷・山・湖をこえて **やみの しろ** へ → ハナを助ける。

**かげマント（追う相手）** ― 毎面の終わりに姿だけ見せて逃げる“ライバル役”。捕まえられそうで捕まえられないことが、次の面へ進む理由になる（原則A・H）。4面でようやく対決。

| 面 | 舞台 | 物語 | 謎解き | 戦い | 仲間 |
|---|---|---|---|---|---|
| **1面**<br>★マップ作成ずみ | 村 → はじまりの森 | 冒頭：ハナと遊ぶ → **かげマントがハナをさらう**（遊ばせる／S1）→ 森へ。<br>ラスト：森を抜けた高台から **遠くに「やみの しろ」が見える（S2）** ＋ 風にのって「たすけて」（S3-1） | **P1 二つの岩の通り抜け**（きこりタロの目撃証言がヒント）＋足あとの三叉路 | 剣の練習（かかし＝村）→ patrol / chase → **charge（突進ネコ）＝1面のヤマ場** | **なし（リイコひとり）** |
| **2面**<br>★つぎに作る | ささやきの谷 | 谷に響く声。ピカと出会う | **クモの巣にとらわれたピカを助ける謎（C1）** → 灯りを詩の順に灯す（色と順番） | **shooter（弾ネコ）**／突進ネコの応用（複数体） | **仲間1＝妖精ピカ 加入**（ヒント・回復が解禁） |
| **3面前半** | 岩山の道 | ワナにかかった猫を見つける | 猫と2人で石板を同時に踏む（P4） | **猫を囲む敵を剣で倒す（救出戦）** → **shield（盾ネコ）＝連携が要る（B1b）** | **仲間2＝猫ミィ 加入**（タップ戦闘が解禁） |
| **3面後半** | 湖と洞くつ | 泉の水鏡にハナが映る（S3-2） | **❄️で湖を凍らせて渡る（P5）** | **flyer（飛ぶ敵）＝魔法必須**／中ボス＝かげマント（逃げる） | **魔法を授かる**（❄️と🔥） |
| **4面** | やみの しろ | 魔王がハナをさらった理由が分かる（S5）→ 救出・エンディング | 最後の鍵＝1〜3面のヒントの総合／💨で仕掛けを動かす | **かげマント戦 → 魔王 3フェーズ（B8）** | 3人そろって最終戦 |

各面の所要目安：10〜15分（3面だけ 20分ほど）。全4面で 55〜70分の1本道＋寄り道。

**1面と2面の役割**（ここだけ先に作り込む）
- **1面 = 「面白いかどうか」を判定する面。** 剣の手ざわり・通り抜けの謎・物語の掴み、の3つが同時に試される。ここが面白くなければ、この先を作っても面白くならない。
- **2面 = 仲間とヒントの仕組みが正しく働くかを試す面。** ピカが入って難易度調整が本格稼働する。
- この2面で娘のプレイテスト（§9-3）を回してから、3面以降に進む。

**謎の3層テンプレ（P3）** ― すべての謎はこの形で書く：

```
観察: プレイヤーが目にする手がかり（岩・足あと・看板の詩）
推理: つなげる一手（「二つの岩＝あの2個だ」）
実行: 実際の操作（間を歩く／灯りを順に触る）
ヒント1(90秒): 場所を絞る 「森の入口のあたり、なんか変じゃない？」
ヒント2(180秒): 手がかりを名指し 「大きい岩が2つならんでるね」
ヒント3(300秒): 答え＋道を光らせる
```

**1面だけはヒントの出し方が違う（ピカがいないため）**

| | 2面以降 | **1面** |
|---|---|---|
| ヒント1 | ピカが独りごとで言う | **リイコが思い出す**（画面上に小さく「（そういえば…森へ 入っていったって 言ってたな）」） |
| ヒント2 | ピカが名指しする | **NPCにもう一度話しかけると、より詳しく話す**（2回目・3回目でセリフが変わる） |
| ヒント3 | ピカが答え＋道を光らせる | **NPCが「ついてきな」と入口まで案内する**／目的地が光る |

> 1面のヒントは「ひとりで考えた」感を守るため、**呼びに行かないと出ない**形（NPC再会話）を主にする。自動で出るのは思い出し（ヒント1）だけ。

## 5. 戦いの設計

**操作（画面ボタン＋キーボード）**

| 操作 | ボタン | キー |
|---|---|---|
| 移動 | 十字（既存） | WASD / 矢印 |
| 剣 | 🗡 | J / Space |
| 魔法 | ❄️🔥（3面後半から）／💨（4面から） | K で切り替え、J で撃つ |
| 猫に指示 | 敵/地面をタップ（既存・**ミィ加入後＝3面から**） | ― |
| 妖精にヒントを聞く | 💡（**ピカ加入後＝2面から**） | H |

> ボタンは**加入・習得したものだけ画面に出す**。1面の画面には十字と🗡だけ＝8才が迷わない。
> ミィ加入前のタップは「会話送り」だけに使う（誤操作で何も起きない状態を作らない）。
> 魔法は**同時に3つ持たせない**。3面後半で❄️→🔥、4面で💨と、1つずつ増やす（覚えることを増やしすぎない）。

**剣と猫、2つの戦い方の役割分担（B1b）**

| | 剣（リイコ） | タップ（ミィ） |
|---|---|---|
| 強み | 狙った瞬間に出せる／コンボで大ダメージ | 危なくない（離れたまま戦える）／同時に別の敵を抑える |
| 弱み | 近づく＝被弾する | 指示から実行までが遅い／サボることがある |
| 併用が要る敵 | 盾ネコ（ミィが正面を引きつけ、リイコが背後）／群れ（1体をミィに任せて1体を斬る） | |

**上達の設計（B2）※実装ずみ**
- 剣は3段コンボ（0.75秒以内に続けて押すと3発目が「ズバッ！」＝1.8倍・射程1.25倍・範囲も広い）
- 敵の攻撃直後の0.45秒に当てると**「ナイス！」＋2倍**
- 突進ネコが**目を回している間**に当てても**「ナイス！」＋2倍**
- ごほうびが付いた時は、ヒットストップも画面ゆれもノックバックも**大きくなる**
- この3つは説明せず、成功した時だけ演出で気づかせる（原則B・要件C-4）

**敵バリエーション（B4/B5）**

**出す順番＝そのとき持っている手段で必ず倒せる順**にする。

| 敵 | 初登場 | 動き | 攻略の答え |
|---|---|---|---|
| patrol いたずらネコ | 1面 | 行ったり来たり | 剣で何とかなる（練習台） |
| chase びっくりネコ | 1面 | 視界に入ると追う | 障害物で振り切る／振り向きざまに斬る |
| shooter 弾ネコ | 2面 | 弾を撃つ | 遮蔽物に隠れて近づく |
| **charge 突進ネコ** | **1面おわり** | ❗溜め→まっすぐ直進→壁で💫目を回す | 溜め中(0.8秒)によける→目を回した所を叩く＝**2倍ダメージ** |
| **shield 盾ネコ** | 3面前半 | 前面ガード | **猫が正面を引きつけ、背後を斬る**（＝ミィ加入直後に置く）／4面では💨でも崩せる |
| **flyer 飛ぶネコ** | 3面後半 | 空中を漂う | **剣が当たらない＝魔法のみ**（＝魔法習得直後に置く） |

**魔王3フェーズ（B8・4面）**
1. 弾を撃つ（既存shooter）→ 遮蔽物を使う
2. 突進を混ぜる → よけて背後（＝2面で覚えたこと）
3. 手下を呼ぶ＋飛ぶ → 猫・妖精・魔法をフル活用（＝3面で覚えたこと）

各フェーズ移行でセリフ＋演出（原則H, J）。**3フェーズは「1〜3面で覚えたことの復習」になるよう設計する**――これが「うまくなった」を最後に実感させる仕掛け（原則C）。

## 6. 仲間の設計

### 仲間0：まだ誰もいない時間（**1面まるごと**）
- リイコの独り言で間を持たせる（「ハナ…！」「森へ 入っていったって 言ってた…」）
- ヒントはNPC再会話＋思い出しで供給する（§4の表・要件D2b）
- **仲間がいないと解けない謎を1面に置かない**（C10）
- **心細さを物語の動機として使う**。2面でピカが加わる嬉しさは、この1面が作る（原則F,I）
- 1面のラストで魔王城が見え、ハナの声が届く → 「ひとりじゃ無理かも」と思わせたところで2面へ

### 仲間1：妖精ピカ（**2面の冒頭**で加入 ― **謎を解いて助ける**）
- 加入イベント：クモの巣にとらわれている → 巣を剣で切る／ランタンの火を近づけて蜘蛛を追い払う
- 見た目：🧚 主人公の斜め上を漂う（上下ゆらぎ＋わずかな遅れ）
- しゃべる：状況テーブルから抽選、同じセリフの連発禁止
  - 新エリア「わあ、ここ広いね！」／敵接近「うしろ、うしろ！」／宝の近く「なんか光ってる気がする…」／長く歩く「リイコ、つかれてない？」
- ヒント：💡ボタンで能動的に、詰まると自動で（§8）
- 回復：C4のルールで薬を持ってくる。演出は必ず**ピカが飛んでいって戻る**（時間が要る＝ありがたみ）

### 仲間2：猫ミィ（**3面前半の冒頭**で加入 ― **助ける**。追従処理は既存を流用）
- 加入イベント：岩山の道でワナにかかり、敵ネコ3体に囲まれている → **リイコが剣で全部倒す**（1〜2面の剣の練習の総仕上げ＝小さな山場）
- 加入の演出（C6）：ワナが外れる → ミィが一周まわって喜ぶ → 「**てきを タップすると ミィが たたかうよ！**」の操作説明 → その場に練習用の敵を1体置く
- 加入後：既存の `followPlayer`（軌跡おいかけ・止まると周回）をそのまま使う
- サボり：指示を受けても15%の確率で1〜2秒 毛づくろい／あくび（吹き出し付き）
- 変なこと：戦闘後に「いま のは わざと よけたんだよ」など
- 例外：HPが半分以下 or ボス戦ではサボらない（C8）
- ピカとの掛け合い（C9）：「ミィ、また寝てる」「ねてない。目をつぶって考えてた」

### 加入で気をつけること（実装メモ）
- engine の `G.partner` を **`G.partners[]`（0〜2人）** に変える。`updateEnemies` / `updateBullets` / `draw` / `handlePointer` の直接参照を全部たどる（C0）
- 未加入キャラのセリフ・掛け合い・ヒントは**絶対に出さない**（存在しない仲間が喋ると世界が壊れる）
- セーブには「誰が加入済みか」を含める（E2）

## 8. 動的難易度の具体ルール（D2〜D4）

```
[詰まり検出]
  同じ面で「新しいフラグが立たない時間」を計測
    90秒 → ピカ ヒント1（場所を絞る）
   180秒 → ピカ ヒント2（手がかりを名指し）
   300秒 → ピカ ヒント3（答え＋目的地を光らせる）
  ※ヒントは会話で割り込む。操作は止めない（うるさくしない）

  ※ピカ加入前（1面）は自動ヒントを使わず、思い出し＋NPC再会話で出す（§4）

[苦戦検出]
  同じ敵に2回やられた
    → その敵の maxHp -20%, attack -1（画面には出さない）
    → ピカ「わたしが やくそう もってきた！」で回復
  同じ敵に3回やられた
    → さらに -20% ＋ 味方が強くなった表現を出す（＝敵が弱くなったとは言わない）
       仲間2人 → 「ミィが 本気を だした！🔥」（攻撃+2・サボり0%）
       ピカのみ → 「ピカが おうえんしてくれた！✨」（剣の攻撃+2）
       仲間ゼロ → 「リイコの けんが 光った！⚔️」（剣の攻撃+2）

[上手いとき]
  1面を無傷 or 被弾1回でクリア
    → 次の面に隠し敵1体＋隠し宝1個（任意の寄り道）
```

**設計の肝**：やさしくなる方向は自動・無言・味方視点。難しくなる方向は任意・報酬付き。

> **実際に○×を付ける表は [FUN-CHECKLIST.md](FUN-CHECKLIST.md) に分けてある。**

| チェック | 内容 |
|---|---|
| 到達可能性（P6） | 各面のスタートから、フラグ順に辿って出口まで到達可能／ソフトロック0 |
| 謎の解答経路 | 各謎に「正解操作を機械的に実行 → フラグが立つ」テスト |

| ヒント段階 | 時間を早送りして 90/180/300 秒でヒントが出るか |
| セーブ復元 | 保存→読込で全状態が一致（**加入済みの仲間を含む**） |
| 仲間0/1/2人の全状態 | 3つの状態それぞれで、更新・描画・入力がエラーなく動く（未加入の仲間を参照しない） |
| 未加入キャラが喋らない | 全セリフを走査し、加入フラグが立つ前のセリフに未加入キャラが登場しない |

### 9-2. 要件チェック（§2の合格条件を1行ずつ）
フェーズ完了時に §2 の表を上から確認し、○/×/保留 を記録する。×が★★★にあるうちは次のフェーズへ進まない。

### 9-3. 娘プレイテスト（これが最終判定）
1面ごとに記録する：

| 観測項目 | 合格ライン |
|---|---|
| 面のクリア時間 | 10〜20分（30分超＝難しすぎ、5分未満＝簡単すぎ） |
