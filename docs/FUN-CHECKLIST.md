# 面白さチェックポイント ― 「これができていれば面白い」を確かめる表

この表が **完成の判定基準**。作った機能の数ではなく、**この表に○が並ぶこと**をゴールにする。
（もとになった考え方 → [GAME_PLAN.md](GAME_PLAN.md) §1 の10原則、要件一覧 → 同 §2）

## つかいかた

| いつ | 何を見るか |
|---|---|
| フェーズが1つ終わったとき | §1 の「その原則に関係するチェック」だけを見る |
| **1つの面が通しで遊べるようになったとき** | **§1 と §2 を全部** |
| 娘さんが遊んだあと | **§3（これが最終判定）** |
| コードを変えたとき | §4（自動チェック）を走らせる |

記号：**○=できている　△=あるが弱い　×=まだ　―=この時点では対象外**

## §3. 娘さんプレイテスト記録（**最終判定はここ**）

面が1つ遊べるようになったら、**口を出さずに横で見る**。記録は `docs/PLAYTEST.md` に追記。

| 観測項目 | 合格ライン | 意味 |
|---|---|---|
| 面のクリア時間 | 10〜20分 | 30分超＝難しすぎ／5分未満＝簡単すぎ |
| ヒント1で解けた謎の割合 | 半分以上 | 「自分で気づいた感」が保てているか |
| ヒント3（ほぼ答え）が必要だった謎 | 面に1つまで | 2つ以上＝謎が不親切 |
| やられた回数 | 面あたり0〜3回 | 0回続き＝簡単すぎ／4回超＝難しすぎ |
| **笑った／声を出した回数** | 面あたり2回以上 | 0回＝キャラ演出が足りない |
| 手が止まった時間の最長 | 5分以内 | 超えたらヒント設計を直す |
| **翌日また遊びたいと言うか** | **Yes** | **これがYesならその面は成功** |
| 自分から「作りたい」と言い出すか | 出れば満点 | 名前・マップ・セリフの提案 |

### 見ているときのメモ欄（毎回コピーして使う）

```
日づけ：            面：
・詰まった場所と、何秒詰まったか：
・笑った場面：
・「つまんない」と言った場面：
・自分で気づいて解けた謎：
・ヒントを使った謎（何段階目？）：
・やられた回数と、やられた相手：
・翌日また遊びたいと言ったか：
・娘さんの提案：
```

## §5. 進めてよいかの判定

各フェーズの終わりに、この2つだけ確認する。

1. **★★★の要件（[GAME_PLAN.md](GAME_PLAN.md) §2）に × が残っていないか**
2. **§1〜§2 のうち、そのフェーズで扱った原則に × が残っていないか**

× が残っているうちは次のフェーズに進まない。
ただし **「面白くない」と分かったら、計画より優先してそこを直す**。この表は計画を守るためではなく、面白くするためにある。
